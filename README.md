# PickPhoto

PickPhoto 是用于快速整理本地照片的桌面应用。可以使用快捷键将照片分到「选用」与「弃用」文件夹，并提供快速预览以及 EXIF 等元信息的查看。

## 功能

- 选择一个照片文件夹，按文件名浏览其当前层的 JPG、JPEG、PNG、WebP 照片
- 在主区域查看大图，在底部胶片条查看小图并跳转
- 使用按钮或快捷键 `Q` 选用、`P` 弃用、`Z` 撤销；方向键切换照片
- 将原文件移动到「选用」或「弃用」目录；两个目标目录可分别自定义到任意位置
- 显示所有可读取的 EXIF 字段、筛选进度和照片状态
- 自动保存每个源文件夹的目标目录与分类结果，再次打开可继续筛选

分类只移动文件，不会删除照片，也不会覆盖目标目录中的同名文件。遇到同名文件或移动失败时，操作会暂停并提示处理。修改目标目录只影响之后的分类，已移动照片保留其实际位置。

## 开发

需要 Go 1.27.1 或以上 Go 版本。

```sh
go run ./cmd/pickphoto
go test ./...
go vet ./...
go tool mygo build
```

如果 macOS 的 `xattr` 被 Python 附带的同名命令覆盖，使用系统版本打包：

```sh
PATH="/usr/bin:$PATH" go tool mygo build
```

筛选记录保存在系统用户配置目录的 `pickphoto/state.db`。缩略图缓存运行期间保存在系统用户缓存目录的 `pickphoto/thumbs`，应用退出时会自动清理缓存。
